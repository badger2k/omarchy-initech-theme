# Initech

A dark [Omarchy](https://omarchy.org) theme for *Office Space*: cubicle-fabric slate, beige CRT plastic, a phosphor-green accent, Milton's red stapler, manila TPS folders and Chotchkie's flair.

![Initech preview](preview.png)

## Install

```
omarchy theme install https://github.com/badger2k/omarchy-initech-theme
```

The backgrounds are original illustrations made for this theme. Each comes in two sizes: 3440×1440 ultrawide, and 2560×1440 (16:9) in the files prefixed `16x9-`.
